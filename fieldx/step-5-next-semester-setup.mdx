title: "Next Semester Setup"
description: "Roll your program into a new term using cohort copy, bulk member moves, and archive."
---

A term rollover is more than creating a new term. Complete the steps in order so student levels, cohorts, assignments, recurring hour logs, and faculty oversight stay aligned.

## Before you begin

Collect:

- New term name, start date, and end date
- Which students remain in their current level
- Which students move from practicum to internship or another level
- Students with incomplete hours who must not move yet
- The cohort or template to copy
- First assignment date
- Hour-log cadence and schedule end date
- Faculty assignments for the new cohort
- LMS-linked course or template information, when applicable

For Canvas-linked programs, also review [Canvas LTI Integration](/fieldx/canvas-lti-integration) before publishing the new course link.

## 1. Create the academic term

Go to **My Program → Terms and Tracks**, select **\+ Add Term**, and enter the term name, start date, and end date.

If application submission windows are enabled, also set the open and close dates and review any level- or track-specific overrides.

## 2. Move students to the correct level or track

Students who are continuing at the same level do not need an unnecessary change. For students moving from practicum to internship:

1. Open **My Program → Members → Students**.
2. Clear any text left in the search field.
3. Filter by the current level.
4. Also filter by the specific track.
5. Select the correct students.
6. Choose **Assign Track**.
7. Select the destination track and level.
8. Confirm the change.
9. Repeat for each track.

<Warning>
  Do not combine different tracks into one bulk change. The confirmation applies one destination to every selected student.
</Warning>

Check pagination before continuing. **Select all** may select only the visible page. Increase the page size or repeat the operation on every page.

Leave a student in practicum if they still need to complete practicum hours. Moving levels closes the old log and starts the new level's hour tracking.

If re-clearance is enabled for level or track changes, affected students will be prompted to complete the new clearance requirements.

## 3. Create the new cohort by copying

<Warning>
  **Copy from existing is available only while the cohort is being created.** A cohort created without choosing a copy source cannot be populated from that source afterward.
</Warning>

1. Open **Cohorts → Create Cohort**.
2. Enter the new cohort name and code.
3. Select **Copy from existing cohort**.
4. Choose the previous cohort or a term-less template cohort.
5. Set **First assignment date**, usually to the term start.
6. Select the new academic term.
7. Leave **Default Signing Faculty** blank if faculty varies by student.
8. Select the correct hours report template.
9. Create the cohort.

After creation, change the cohort filter to **All terms** if the new cohort is not immediately visible.

## 4. Verify what copied

Ordinary one-time assignments copy with due dates shifted relative to the new first assignment date. Open the new cohort and verify several dates rather than assuming the shift worked.

Recurring hour-log schedules require separate attention:

- Do not assume the previous hour-log schedule copied
- Open the new cohort's **Assignments → Schedules** segment
- Recreate the schedule using the new term start and end dates
- Set an end date
- Confirm the first generated assignment after the schedule runs

A schedule is a generator, so it appears under **Schedules** before its first assignment is emitted.

See [8. Setting Up Recurring Tasks](/fieldx/setting-up-recurring-tasks).

## 5. Move students into the new cohort

There is no reason to remove students from the overall program when changing cohorts.

For a small roster, add students from the new cohort's **Members** segment.

For a large roster, use **Ask AI**:

> Add the students in \[old cohort\] to \[new cohort\].

Review the proposed roster, remove anyone who should not move, and approve the action. Allow the operation time to finish, then compare the old and new rosters.

## 6. Add faculty and configure signing responsibility

Inside the new cohort:

1. Open **Members**.
2. Add the faculty or instructors responsible for the cohort.
3. Assign faculty to students where needed.
4. Set default or per-student signing faculty.

Some faculty-assignment controls remain unavailable until at least one faculty member belongs to the cohort.

## 7. Archive the previous cohort

Archive completed cohorts instead of deleting them. Archiving removes them from the active view while preserving:

- Student hours
- Forms and responses
- Reports and signatures
- Site history
- Audit records

Use **Show Archived** to find or restore an archived cohort.

## Rollover checklist

- [ ] Create the new term
- [ ] Clear stale search text before filtering members
- [ ] Move students level by level and track by track
- [ ] Leave incomplete students in the prior level
- [ ] Check every pagination page
- [ ] Create cohorts using **Copy from existing**
- [ ] Set first assignment date to the intended anchor
- [ ] Verify copied due dates
- [ ] Recreate the hour-log schedule with an end date
- [ ] Move the correct students into the new cohort
- [ ] Add faculty before assigning signing responsibility
- [ ] Confirm the cohort belongs to the correct term
- [ ] Archive the previous cohort only after verification
