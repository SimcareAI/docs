**View as Student** lets Program Admins see FieldX exactly as a specific student sees it. Use it to inspect the student experience without submitting changes on their behalf.

## When to use it

- Walking through a student's clearance issue without asking them to screen-share
- Confirming a recurring assignment is showing up on the right day
- Testing a new cohort, form, or report from the student's perspective
- Onboarding new staff by showing them what students see

## Starting a session

You can launch View as Student from several places:

1. **Program Settings → Members → Students** — **View as Student** on the student row
2. **Cohorts → cohort → Members** — **View as Student** on the student row
3. **Student Details modal** — the **View as Student** button at the top

SimCare opens the student's Field Experience dashboard in the same browser tab.

## The amber banner

While impersonation is active, a sticky amber banner stays pinned to the top of every page. The banner shows:

- The student's name
- A live **countdown timer** (default 1 hour)
- An **Exit Student View** button — click to return to the Program Admin **Overview**

You'll see the student's data exactly as they would — same tabs, same urgent badges, same locked screens if they haven't completed clearance.

</Frame>

## What's read-only

View as Student is a strict read-only mode. You can navigate freely, but **you cannot**:

- Submit a form on the student's behalf
- Log hours
- Send a join request
- Approve, reject, or sign anything
- Modify the student's profile, sites, or supervisors

If you try a blocked action, FieldX shows a read-only message.

## Audit log

Every impersonation session is recorded in your **Activity Log** (Program Settings → Activity Log):

- Who started the session
- Who they impersonated
- Session start time and the student and program being viewed
- An end event when you exit the view

Coordinators can review past impersonations to satisfy security or accreditation requirements.

## Session lifetime

- **Expires after 1 hour** — use the countdown in the banner to see the remaining time.
- **Switching students** — exit the current preview before opening another student.
- **Shared across browser tabs** — preview mode uses your browser session. Check the amber banner in other SimCare tabs and exit preview before resuming admin work.

<Tip>
  If your hour runs out and you still need to debug, just click **View as Student** again on the same student. A fresh session starts.
</Tip>

## Faculty and supervisor accounts

For site supervisors, use the dedicated [View as Supervisor](/fieldx/view-as-supervisor) flow from **Members → Supervisors**. There's no dedicated "view as faculty" — faculty have a lighter dashboard you can test by joining a cohort as faculty using the cohort join code.
