Use the Canvas LTI to let faculty create a FieldX cohort from a prepared template and let students join the correct cohort from their Canvas course.

## Before you begin

Confirm:

- The institution's Canvas integration is enabled
- The specific FieldX program is connected
- The Canvas course is available
- The FieldX cohort template is complete
- Program Admin and faculty test accounts can access both systems

<Warning>
  Seeing SimCare in Canvas does not prove the FieldX program is connected. Verify that the **Field Experience** option appears in the assignment picker.
</Warning>

## Launch SimCare versus the assignment picker

These Canvas tools serve different purposes:

| Tool | What it does |
| --- | --- |
| **Launch SimCare** | Authenticates the user and opens SimCare; it does not create or select a cohort |
| **SimCare Assignment Picker** | Connects Canvas content to FieldX and lets the course use a cohort template |

Use **Launch SimCare** for access. Use the assignment picker for cohort creation and enrollment.

## Link a cohort template

1. Open the Canvas course.
2. Create or open the intended module.
3. Select **\+** to add content.
4. Choose **External Tool**.
5. Select **SimCare Assignment Picker**.
6. Confirm that **Field Experience** appears.
7. Choose the intended cohort template.
8. Select **Link Selection**.
9. Select **Add Item**.
10. Publish the module item only after testing.

## Choose the template carefully

Before linking, open the template in FieldX and confirm:

- Standard forms and report templates are present
- Reusable settings are correct
- The hours report template is correct
- No real students belong to the template
- The template is not attached to an academic term
- The template name clearly distinguishes it from live cohorts

## Verify the generated cohort

Open the new Canvas item once as the responsible faculty or Program Admin.

In FieldX, confirm:

- A new cohort was created
- The name matches the Canvas course or agreed naming convention
- The correct academic term is selected
- The expected forms and settings are present
- Faculty are in the cohort
- The student enrollment path opens the correct cohort

## Assignments and schedules

Do not assume every time-based item copied correctly.

After the cohort is created:

1. Review the copied one-time assignments and due dates.
2. Open **Assignments → Schedules**.
3. Recreate or verify the hour-log schedule using the new term's dates.
4. Set a schedule end date.
5. Check the first generated assignment after the schedule runs.

Existing emitted weekly assignments are historical records and do not become future-term assignments.

See [8. Setting Up Recurring Tasks](/fieldx/setting-up-recurring-tasks) and [Next Semester Setup](/fieldx/step-5-next-semester-setup).

## Test student enrollment

Before distributing the link:

1. Open the Canvas item with a controlled student account.
2. Confirm the displayed cohort name is correct.
3. Continue into Field Experience.
4. Confirm the student joins the intended cohort.
5. Verify the expected assignments and clearance state.
6. Remove or archive controlled test data if needed.

## Troubleshooting

**Launch SimCare is missing**

Ask institutional IT to confirm the Canvas tool is enabled for the course.

**Field Experience is missing**

The institution may be connected while the FieldX program is not. Contact FieldX support with the institution, program, and course information.

**Wrong cohort was created**

Unpublish the Canvas item, identify the selected template, and correct the link before students use it.

**Students open SimCare but do not join a cohort**

Confirm the course uses the assignment-picker link rather than only the general Launch SimCare link.

**A schedule or assignment is missing**

Check the new cohort's Assignments and Schedules segments. Recreate the hour-log schedule with the new term dates.
