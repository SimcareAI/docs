Cohorts are the primary way to organize students into groups — class sections, academic tracks, or placement groups. Each cohort has its own assignments, member roster, and faculty oversight.

![Cohorts Overview](/images/coord_cohorts_1.png)

## Creating a new cohort

Open the **Cohorts** tab and click **Create Cohort**.

![Create Cohort Interface](/images/coord_cohorts_2.png)

The create modal asks for:

| Field | Notes |
| --- | --- |
| **Track Code** _(required)_ | Short identifier, e.g. `COU-501-A` |
| **Track Name** _(required)_ | Descriptive name |
| **Description** | Optional context |
| **This is a template cohort** | Marks the cohort as a term-less template used as a copy source for each real intake — see [Template cohorts](#template-cohorts) |
| **Copy from existing cohort** | Clone eligible one-time assignments and settings. Verify schedules separately and recreate hour-log schedules for the new term |
| **First assignment date** _(when copying)_ | Shifts all source assignment dates by the same offset |
| **Academic Terms** | Multi-select — student placements are auto-created using this term |
| **Default Signing Faculty** | Default supervisor name used for report signatures |
| **Hours Report Template** | Pre-selected with your program's newest template. Choose **Default — standard report** only if your program does not use custom hour categories (e.g. direct, indirect, supervision). |

<Warning>
  **Need to change the hours template?** You can change it yourself from the cohort's **Settings → Hours Report Template** until students start logging hours — see [Changing the hours report template](#changing-the-hours-report-template). Once any hours are logged or reports are generated, the template is locked.
</Warning>

Click **Create Cohort** to save.

<Tip>
  The **Copy from existing cohort** \+ **First assignment date** combo is the fastest way to spin up a new semester — see [Next Semester Setup](/fieldx/step-5-next-semester-setup).
</Tip>

## Template cohorts

Toggle **This is a template cohort** in the create or edit modal to mark a cohort as a template. A template is a term-less cohort you build once and copy from for each real intake — add your standard forms, report templates, and reusable settings, then use **Copy from existing cohort** each term to stamp out the real cohort.

<Warning>
  **Copy from existing is available only while creating the new cohort.** After creation, verify every copied due date and recreate the term's hour-log schedule with the correct start and end dates.
</Warning>

Template cohorts follow a few rules:

- **No academic terms.** Turning the toggle on clears any term selection, and terms cannot be attached later. The term is chosen when you create a real cohort from the template.
- **Flagging an existing cohort requires detaching its terms first.** If the cohort still has terms attached, the save is rejected and the error names the terms — remove them before flagging.
- **Copies are normal cohorts.** Copying from a template never carries the template flag over, so the new cohort behaves like any other.
- **Excluded from competency attainment.** A template is not a student population, so it never appears in competency attainment cohort pickers or figures.
- **Always visible.** The cohort grid's term filter skips templates, so a term-less template never disappears from your management view.

A **Template** tag appears on the cohort card, the cohort breadcrumb, Cohort Settings, and the form and report assignment pickers so templates are easy to tell apart. Templates stay selectable in those pickers — assigning forms and report templates to the template is how you build out its content.

## Editing a cohort

Per-row actions (when you hover any cohort card) include edit, archive, unarchive, permanent delete, and generate join code. In edit mode you can also:

- Upload a **Cohort Logo** (16:9, max 5MB; JPEG, PNG, WebP, or GIF) — appears in the cohort header for everyone
- Update name, code, description, terms, and signing faculty

## Inside a cohort

Click a cohort card to open its dedicated dashboard.

![Cohort Dashboard](/images/coord_cohorts_3.png)

You'll see four centered sub-tabs:

| Sub-tab | What's here |
| --- | --- |
| **My Tasks** | Tasks and oversight specific to this cohort, filtered by `Pending`, `In Progress`, `Completed`, `Rejected` |
| **Assignments** | One-time assignments and recurring schedules — create, stop, edit due dates |
| **Members** | Students and instructors in the cohort — bulk-assign faculty, generate join code, send alerts |
| **Settings** | General settings, hour requirements, and the hours report template |

Click **Back to cohorts** in the header to return.

### Members sub-tab

Two segments: **Students** / **Instructors**. The top-right **\+ Add Student** / **\+ Add Instructor** buttons open the **Add Program Members to Cohort** modal — which doubles as an **Invite to Program** flow if you need to add a brand-new email.

Per-row actions include **View as Student** (impersonate read-only) and bulk **Assign same faculty to all** to set faculty for many students at once.

You can also click **Send Alert** to push a one-off notification to a student.

### Assignments sub-tab

Two segments: **Assignments** (one-time) and **Schedules** (recurring). The **\+ Create** button opens the program-wide assignments builder. Stop a schedule any time — existing emitted assignments are preserved, but no new ones are generated.

### Settings sub-tab

The available segments are:

- **General Information** — name, code, description, terms, default signing faculty, cohort logo
- **Hour Requirements** — per-track and per-certificate hour requirements with qualifying activity types
- **Hours Report Template** — preview the active DocuSeal hours-report template, or change it while the cohort is unstarted. See [Changing the hours report template](#changing-the-hours-report-template).
- **Learning Contract** _(programs with Learning Contracts enabled)_ — pick which Learning Contract variant students in this cohort complete, or leave on **Program default** to use the standard contract. Variants are defined at the program level under **My Program → Settings → Learning Contract Variants**. See [Learning Contract variants](/fieldx/step-0-2-customization-settings#learning-contract-variants).

## Changing the hours report template

You can change a cohort's hours report template yourself, as long as no one has started logging hours. Open the cohort's **Settings** sub-tab and select **Hours Report Template**.

If the cohort is unstarted, a panel shows the current template with a note that it can still be changed:

1. Click **Change template**.
2. Pick the new template from the list — active templates from your program, public templates, and **Default — standard report**.
3. Click **Continue**, review the confirmation, then click **Confirm change**.

The confirmation reminds you what the change affects: students see the new template's activity types when logging hours, and generated reports use its layout.

Once students begin logging hours or reports are generated, the tab shows a **Template locked** banner with the entry, student, and report counts, and the template can no longer be changed.

<Note>
  Choose **Default — standard report** only if your program does not use custom hour categories (e.g. direct, indirect, supervision).
</Note>

## Archiving a cohort

When a term ends, archive the cohort instead of deleting it:

1. From the **Cohorts** tab, hover the cohort and click the archive action
2. Click **Show Archived** in the header to see archived cohorts; **Hide Archived** to hide them again

Archiving hides the cohort from your active dashboard but preserves all student data, hours, and signed forms. You can **Unarchive** any time. Permanent delete is also available but rarely needed.

Both actions open a confirmation prompt showing the cohort name before anything changes. **Archive** asks you to confirm and notes the cohort can be restored later. **Permanent delete** warns that the action cannot be undone and uses a red confirm button.
