**Find Clients with AI** matches a short description to an existing AI client in your school’s library. Use it when you know the presenting issue or skill, but not which client to assign.

Open it from **Courses** in the top navigation, then click the **Find Clients with AI** tab (`/classes?tab=find-clients`).

## How a search works

<Steps>
  <Step title="Describe what you need">
    Type in the search field. You can mention symptoms, conditions, demographics, or a skill (for example, “adolescent with panic attacks” or “motivational interviewing”). Click **How does this work?** in the top right for a short reminder.
  </Step>
  <Step title="Submit the search">
    Press the arrow button (or Enter). SimCare searches the clients available to your school and returns the best match.
  </Step>
  <Step title="Review the client">
    You’ll see a card for the matched client. From here you can **View Details**, **Create Assignment**, or **Find Another Client** to search again.
  </Step>
</Steps>

The placeholder on the search field is **Ask SimCare to generate a client for you...** — the tool finds an existing client; it does not build a brand-new one. To author a custom client, use the [Client builder](/simulations/client-builder).

## Assign the client to a course

<Steps>
  <Step title="Click Create Assignment on the result card">
    Choose which of **your** courses should receive the assignment.
  </Step>
  <Step title="Configure the assignment">
    The same case-assignment builder used inside a class opens: title, due date, settings, assessments, and evaluation. See [Creating assignments](/simulations/creating-assignments) for each step.
  </Step>
</Steps>

**View Details** opens prompt customization so you can inspect (and optionally adjust) how the client is set up before you assign it.

## If search doesn’t work

**No cases available.** Your school’s library is empty or you don’t have access to any clients. Ask your program admin to add or share cases.

**Unable to load cases.** Refresh and try again. If it persists, contact [hello@simcare.ai](mailto:hello@simcare.ai).

**The match isn’t right.** Click **Find Another Client** and try a more specific description (age, diagnosis, setting, or the skill you want graded).
