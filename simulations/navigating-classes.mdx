title: "Navigating your classes"
description: "How faculty open Courses and move between My Courses, Course Catalog, Find Clients with AI, Forms, and Program Courses."
---

As an instructor, your teaching workspace lives under **Courses**. That’s where you create classes, clone catalog templates, search for AI clients, manage forms, and (if you’re a program admin) review every course in your program.

## Opening Courses

<Steps>
  <Step title="Sign in">
    Sign in to SimCare with the instructor account your program gave you.
  </Step>
  <Step title="Click Courses in the top navigation">
    In the header, click **Courses**. Instructors land on `/classes`. SimCare opens the **My Courses** tab automatically (`/classes?tab=courses`).
  </Step>
</Steps>

If you already have a class open, use **Back** on the class page to return to the tab list. The active tab is preserved, so returning from a program course takes you back to **Program Courses**, not **My Courses**.

<Note>
  Students click the same **Courses** item and go to **My Learning** instead. These pages are for faculty and program admins.
</Note>

## Who can do what

| Role | What you can do |
| --- | --- |
| **Teacher** | Create and join classes, assign work, grade, and view analytics for classes you own or co-teach |
| **Program admin / teacher admin** | Everything a teacher can do, plus [Program Courses](/simulations/program-courses) and [Curriculum builder](/simulations/curriculum-builder) |

## The tabs

Across the top of the page you’ll see a row of tabs. Click any tab to switch — the URL updates so you can bookmark or share a specific view.

| Tab | What it’s for |
| --- | --- |
| **[My Courses](/simulations/my-courses)** | Classes you teach: create, join, duplicate, export, then open a class to assign work |
| **[Course Catalog](/simulations/course-catalog)** | Ready-made simulation courses you can clone into a class |
| **[Find Clients with AI](/simulations/find-clients-with-ai)** | Describe a client or skill, get a matching AI client, then assign it |
| **[Forms](/simulations/forms)** | Forms you own and forms shared with your program |
| **[Program Courses](/simulations/program-courses)** | Every course in your program, grouped by owner (program admins only) |

<Tip>
  **Program Courses** only appears if you have program-admin (or teacher-admin) access. If you don’t see it, you still have the other four tabs.
</Tip>
