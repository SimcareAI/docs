title: "Ending a session"
description: "When you're ready to wrap up, click End Call to finish the session and start generating feedback."
---

When you're ready to wrap up, click the red **End Call** button in the bottom right of the session window.

## Confirm before ending

A confirmation modal appears:

- **Title:** End this conversation?
- **Body:** Your session will be saved and feedback will be generated.

Click **End Conversation** to finish, or **Cancel** to keep going. While cleanup runs you'll briefly see **Preparing feedback…** on the button.

## What happens next

After you confirm, one of three things happens depending on how your instructor set up the assignment:

### 1. Straight to feedback (default)

You're sent to a loading screen while SimCare processes the conversation. A progress bar and status messages (e.g., "Generating feedback for your instructor…") update as the AI works. Once it finishes — typically under a minute — you'll see your full feedback report.

### 2. Post-session assessments first

If your instructor enabled post-session work, you'll be asked to complete one or more written tasks before viewing feedback:

- **Problem Statement**
- **Differential Diagnosis**
- **Risk Assessment**
- **Safety Planning**
- **Treatment Planning**
- **SOAP Note**
- **Reflection**
- **Self-Annotated Transcript** or a custom task, if assigned

<Note>
  Complete each assigned assessment and click **Submit**. Feedback availability still depends on your instructor’s release settings.
</Note>

### 3. Paired clinical-trial case

For some research-enabled cases, a **Post-Simulation Choice** modal appears asking if you'd like to complete a paired follow-up case before viewing feedback. This is optional.

## Short sessions

If there is not enough interaction to evaluate, you may see **“This session was too short to generate feedback”** instead of a full report. The page explains that more interaction data is needed and shows a conversation preview. Click **Dashboard** to return to **Simulations**.

## Hidden feedback

If your instructor set this assignment to **hide feedback from students**, you'll see a confirmation screen instead of the feedback report. The AI feedback is still generated and visible to your instructor — they'll release it when they're ready.

## Saved automatically

Your session — including transcript, audio, and video (if your camera was on) — is saved automatically. You can return to feedback any time from your assignment dashboard or session library.

## Find a session in History

Open **History** in the navigation (on a narrow screen, open **Menu** first). This opens **Your Simulation Library**.

1. Use **Quick search** to locate a client.
2. Use the completion-status filter to switch between **All**, **Complete**, and **Incomplete**.
3. Check the client name, status, and date to find the session you want.

### Session actions

The actions available depend on the session:

| Action | When to use it |
| --- | --- |
| **Practice** | Practice with that client. For graded work, start from the course assignment instead. |
| **Generate Feedback** | Request feedback for an incomplete session when this action is available. Very short sessions may not contain enough interaction for a report. |
| **View Feedback** | Open an available session report. See [Understanding the AI feedback](/simulations/understanding-ai-feedback). |
| **Delete case** | Appears on sessions that offer deletion. Do not use it to troubleshoot missing feedback or an assignment submission. |
| **Cannot delete** | Deletion is unavailable for that session. |

### Common library questions

**I can't find my session.** Clear **Quick search**, set the status filter to **All**, and check that you are using the same account. If there are several pages, use the page controls below the table.

**The session says Complete, but View Feedback is disabled.** Completion status and feedback access are separate. For coursework, check the assignment and your instructor's feedback-release settings. If access remains unclear, contact your instructor or [hello@simcare.ai](mailto:hello@simcare.ai) with the client name and session date.

**Does Practice count toward my assignment?** Use **Courses** and start the actual assignment for coursework. Do not use the library's Practice button as a substitute for **Start Assignment**.
