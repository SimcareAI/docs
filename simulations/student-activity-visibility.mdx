---
title: "Student activity visibility for program admins"
description: "Let program admins see every case a student in your program has run, including self-directed practice, from the student's Case History page."
---

Student activity visibility controls what program admins can see on a student's **Case History** page. By default, program admins see only a student's assignment submissions. Turn on **Admins can view all student activity** to also show the student's self-directed practice cases.

Use this setting when your program's admins need a full picture of each student's practice, for example to track engagement outside of assigned work.

## Who is affected

| Role | Setting off (default) | Setting on |
| --- | --- | --- |
| **Program admins** | Assignment submissions only | Every case the student has run with feedback, plus the Assignments list |
| **Teachers** | Assignments in their classes | No change |

The setting applies only to people who are **students** in your program. Program admins can't see the practice sessions of teachers or other admins, even when the setting is on.

## Turn on all student activity

<Info>
  Only program admins can change this setting. Other program members can open the tab and view the current value, but the toggle is disabled for them.
</Info>

<Steps>
  <Step title="Open Program Management">
    Go to **Program Management** and select a single program in the header.
  </Step>
  <Step title="Open the Student Visibility tab">
    Select the **Student Visibility** tab.
  </Step>
  <Step title="Turn on the toggle">
    Turn on **Admins can view all student activity**. The change saves right away, and **Saved.** appears below the toggle.
  </Step>
</Steps>

To go back to showing only assignment submissions, turn the toggle off. The change takes effect immediately.

## What admins see

When the setting is on, a student's **Case History** page shows two views:

- **All activity**: every case the student has run that already has feedback. This includes self-directed practice and assignment cases from classes in your program. Select **Load More** to see older cases.
- **Assignments**: the student's assignment submissions, the same list admins saw before.

In-progress and ungraded assignment work doesn't appear in **All activity**. Switch to **Assignments** to review it.

Admins can open the feedback page for any case listed in **All activity**.

<Note>
  If a student belongs to more than one program, admins only see assignment cases from classes in their own program. Assignment cases from the student's other programs stay hidden. Archived programs don't grant access.
</Note>
